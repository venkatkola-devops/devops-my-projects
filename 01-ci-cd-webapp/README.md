# Project 01: CI/CD Pipeline for Web Application

## Business Scenario
This project simulates a real client web application developed in a consulting
company like 247labs, where fast and reliable deployments are critical.

## Problem
Manual builds and deployments often lead to errors, delays, and broken releases.

## Solution
A CI/CD pipeline was implemented to automatically build and test the application
whenever code is pushed or a pull request is created.

## Tools Used
- GitHub
- GitHub Actions
- Python

## Outcome
- Automated build and test
- Early detection of failures
- Production-ready workflow
